API Reference

The core types you'll use in nearly every program: ConnectionProfile, AuthMethod, SSHDispatcher, and BaseConnection (the class every vendor driver subclasses). Vendor-specific behavior beyond this shared surface is documented on each driver's subclass — see PLATFORMS.md for the full list.

AuthMethod

Defined in Sources/Channel.swift:

public enum AuthMethod: Sendable {
    case password(String)
    case keyFile(path: String, passphrase: String? = nil)
    case sshAgent
    case none
}

keyFile accepts an optional passphrase: for passphrase-protected keys. sshAgent defers to a running SSH agent. There is currently no ssh_config_file-style option — Swiftmiko talks to the transport directly rather than shelling out to a system SSH client.

SSHDispatcher

The entry point for opening connections. Defined in Sources/SSHDispatcher.swift.

connectHandler(profile:autoConnect:)

public static func connectHandler(
    profile: ConnectionProfile,
    autoConnect: Bool = true
) async throws -> BaseConnection

Looks up the registered driver for profile.deviceType, attaches the correct transport channel (SSH, Telnet, or serial — inferred from a _telnet/_serial suffix), and — unless autoConnect is false — connects and runs session preparation before returning. Throws SwiftmikoError.connectionFailed if deviceType isn't registered.

redispatch(_:deviceType:sessionPreparation:)

public static func redispatch(
    _ connection: BaseConnection,
    deviceType: String,
    sessionPreparation: Bool = true
) async throws -> BaseConnection

Constructs a new driver instance for deviceType and transplants the original connection's already-open channel onto it — no reconnect, no re-authentication. Used for jumping through a terminal server onto a different device type (see the terminal server example). The returned connection owns the channel; stop using the one you passed in.

Registering or overriding a driver

DispatcherRegistry.shared lets you register a deviceType that has no built-in driver yet, or override an existing one (e.g. to swap in a test double): 

await DispatcherRegistry.shared.registerConnection("some_new_device") {
    SomeDriverSSH(profile: $0, channelProvider: nioSSHChannelProvider)
}

A registration made this way takes priority over anything in SSHDispatcher.defaultConnectionFactories.

BaseConnection

The transport-neutral base class every vendor driver subclasses (equivalent to Netmiko's base_connection.py). Defined in Sources/BaseConnection.swift. Methods marked open are overridden per-vendor where the CLI behaves differently; the signatures below are the shared contract every driver honors.

Sending commands

open func sendCommand(
    _ command: String,
    readTimeout: TimeInterval? = nil,
    expectString: String? = nil,
    stripPrompt: Bool = true,
    stripCommand: Bool = true,
    cmdVerify: Bool = true,
    autoFindPrompt: Bool = true
) async throws -> String

Writes the command, then waits for the device's prompt to reappear (or for expectString, a regex, if supplied instead) before returning. Strips the echoed command and trailing prompt from the output by default. 

@discardableResult
open func sendCommandTiming(
    _ command: String,
    readTimeout: TimeInterval = 2.0,
    expectString: String? = nil,
    stripPrompt: Bool = true,
    stripCommand: Bool = true,
    cmdVerify: Bool = true
) async throws -> String

A purely delay-based send — waits a fixed amount of time rather than for a prompt match. Use it for interactive prompts that don't cleanly match a pattern (Netmiko's send_command_timing). 

@discardableResult
open func sendMultiline(
    _ commands: [String],
    expectString: String
) async throws -> String

Sends several commands, each waiting for the same shared expectString. Doesn't assume config mode, unlike sendConfigSet.

Configuration changes

@discardableResult
open func sendConfigSet(
    _ commands: [String],
    exitConfigMode: Bool = true,
    readTimeout: TimeInterval? = nil,
    maxLoops: Int? = nil,
    stripPrompt: Bool = false,
    stripCommand: Bool = false,
    configModeCommand: String? = nil,
    cmdVerify: Bool = true,
    enterConfigMode: Bool = true,
    errorPattern: String = "",
    terminator: String = "#",
    bypassCommands: String? = nil
) async throws -> String

Enters config mode, runs each command in commands in order, and exits config mode again — all by default. Pass a non-empty errorPattern to have it throw SwiftmikoError.commandFailed as soon as any command's output matches. Throws SwiftmikoError.configModeNotSupported on platforms without a config mode.

Persisting the change (Cisco's write memory / copy run start) is a separate step — see saveConfig() below.

Vendor subclasses

connectHandler returns a plain BaseConnection. Behavior specific to a vendor family — things Netmiko models with mixins — lives on that family's subclass, and you'll need to downcast to reach it: 

// cisco_ios resolves to CiscoIOSSSH, a CiscoBaseConnection subclass —
// saveConfig() is declared there, one level below BaseConnection.
let connection = try await SSHDispatcher.connectHandler(profile: profile) as! CiscoBaseConnection

var output = try await connection.sendConfigSet(["logging buffered 100000"])
output += try await connection.saveConfig()
await connection.disconnect()

CiscoBaseConnection (Sources/CiscoBaseConnection.swift) adds saveConfig(), and overrides enterEnableMode/exitEnableMode/exitConfigMode for the Cisco family. Junos-style commit() is not yet ported for Cisco XR / Juniper Junos / Palo Alto — check PLATFORMS.md before relying on a given driver's surface beyond the BaseConnection contract.

SwiftmikoError conforms to LocalizedError, so error.localizedDescription gives a readable message for each case.
