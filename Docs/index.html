Swiftmiko

A native Swift port of Netmiko — one consistent async API for SSH/Telnet automation across 150+ network vendor CLIs, from Cisco IOS to Juniper JunOS to MikroTik RouterOS and far beyond.

⚠️ Pre-alpha status Swiftmiko is under active development and has not yet been verified end-to-end against real or emulated hardware for every driver. APIs may change without notice until the first tagged release. See PLATFORMS.md in the repository root for current per-platform testing status.

What is Swiftmiko?

Swiftmiko brings Netmiko's device-abstraction model to Swift: one consistent API — connect(), sendCommand(_:), sendConfigSet(_:), enterEnableMode(secret:) — across the entire supported vendor list, so you write the same code whether you're talking to a Cisco switch or a Juniper router. If you already know Netmiko, Swiftmiko should feel immediately familiar; if you're coming from Swift, it should feel like a normal, modern async Swift library built on SwiftNIO. 

import Swiftmiko

let profile = ConnectionProfile(
    host: "192.168.1.1",
    deviceType: "cisco_ios",
    username: "admin",
    auth: .password("changeme")
)

let connection = try await SSHDispatcher.connectHandler(profile: profile)
try await connection.enterEnableMode(secret: "enablepass")
let output = try await connection.sendCommand("show version")
print(output)
await connection.disconnect()

Why a Swift port?

Swiftmiko is a from-scratch reimplementation, not a wrapper or bridge — there is no Python runtime involved anywhere. Every driver was translated by hand from Netmiko's actual source, preserving vendor-specific quirks and workarounds, so behavior that hasn't been validated against real hardware isn't silently "fixed" along the way. It's built for Apple platforms: native async/await, no Combine, and a transport layer on top of SwiftNIO instead of shelling out to a system SSH client.
