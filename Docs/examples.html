Examples

Common connection patterns, translated from Netmiko's own examples into Swift. readSecurely(_:) below is a stand-in for however your program prompts for credentials — don't hardcode real passwords. This page is a curated subset; see EXAMPLES.md in the repository root for the complete, continuously updated set, plus the runnable SwiftUI apps under Examples/.

Simple connection

import Swiftmiko

let profile = ConnectionProfile(
    host: "cisco1.lasthop.io",
    deviceType: "cisco_ios",
    username: "pyclass",
    auth: .password(readSecurely("Password: "))
)

let connection = try await SSHDispatcher.connectHandler(profile: profile)
print(try await connection.findPrompt())
await connection.disconnect()

Enable mode

let profile = ConnectionProfile(
    host: "cisco1.lasthop.io",
    deviceType: "cisco_ios",
    username: "pyclass",
    auth: .password(readSecurely("Password: ")),
    secret: readSecurely("Enter secret: ")
)

let connection = try await SSHDispatcher.connectHandler(profile: profile)
try await connection.enterEnableMode(secret: profile.secret ?? "")
print(try await connection.findPrompt())
await connection.disconnect()

Executing a show command

let connection = try await SSHDispatcher.connectHandler(profile: profile)
// sendCommand automatically strips the command echo and trailing prompt.
let output = try await connection.sendCommand("show ip int brief")
await connection.disconnect()
print(output)

Commands that prompt mid-command

Some commands prompt for more input while running (for example, a confirmation before deleting a file). Two approaches:

Timing-based

sendCommandTiming is purely delay-based — it doesn't wait for a prompt match, which suits interactions like this one:

var output = try await connection.sendCommandTiming(
    "delete flash:/test3.txt",
    stripPrompt: false,
    stripCommand: false
)
if output.contains("Delete filename") {
    output += try await connection.sendCommandTiming("\n", stripPrompt: false, stripCommand: false)
}
if output.contains("confirm") {
    output += try await connection.sendCommandTiming("y", stripPrompt: false, stripCommand: false)
}

Expect-string based

The same interaction using sendCommand's expectString parameter — a regex Swiftmiko waits for instead of the connection's normal prompt pattern:

var output = try await connection.sendCommand(
    "delete flash:/test4.txt",
    expectString: "Delete filename", stripPrompt: false, stripCommand: false
)
output += try await connection.sendCommand("\n", expectString: "confirm", stripPrompt: false, stripCommand: false)
output += try await connection.sendCommand("y", expectString: "#", stripPrompt: false, stripCommand: false)

Slowing everything down with globalDelayFactor

ConnectionProfile.globalDelayFactor scales every internal settle-delay a driver requests — set it once rather than per call:

var profile = ConnectionProfile(
    host: "cisco1.lasthop.io", deviceType: "cisco_ios",
    username: "pyclass", auth: .password(readSecurely("Password: "))
)
profile.globalDelayFactor = 2.0 // doubles every internal delay this driver requests

let connection = try await SSHDispatcher.connectHandler(profile: profile)
let output = try await connection.sendCommand("show ip arp")

Configuration changes

let connection = try await SSHDispatcher.connectHandler(profile: profile) as! CiscoBaseConnection

var output = try await connection.sendConfigSet(["logging buffered 100000"])
output += try await connection.saveConfig()
await connection.disconnect()

sendConfigSet automatically enters and exits config mode; saveConfig persists it (declared on CiscoBaseConnection — see the vendor subclasses note).

From a file

import Foundation

let contents = try String(contentsOfFile: "config_changes.txt", encoding: .utf8)
let commands = contents
    .trimmingCharacters(in: .whitespacesAndNewlines)
    .components(separatedBy: .newlines)

let connection = try await SSHDispatcher.connectHandler(profile: profile) as! CiscoBaseConnection
var output = try await connection.sendConfigSet(commands)
output += try await connection.saveConfig()

SSH keys

let profile = ConnectionProfile(
    host: "cisco1.lasthop.io", deviceType: "cisco_ios",
    username: "testuser",
    auth: .keyFile(path: "~/.ssh/test_rsa")
)

let connection = try await SSHDispatcher.connectHandler(profile: profile)
let output = try await connection.sendCommand("show ip arp")

AuthMethod.keyFile also accepts a passphrase: for passphrase-protected keys; AuthMethod.sshAgent defers to a running SSH agent instead.

Session log

SSHDispatcher.connectHandler doesn't take a session-log parameter, so construct the concrete driver directly — sessionLog: is a BaseConnection initializer parameter every driver inherits:

let connection = CiscoIOSSSH(
    profile: profile,
    sessionLog: SessionLogConfig(filePath: "output.txt", recordWrites: true),
    channelProvider: nioSSHChannelProvider
)
try await connection.connect()
let output = try await connection.sendCommand("show ip int brief")
await connection.disconnect()

Passwords and secrets on the profile are automatically redacted in the log. Set recordWrites: false (the default) to log only what's read back from the device, not what was sent.

Secure Copy

let connection = try await SSHDispatcher.connectHandler(profile: profile)

// A secure copy server must be enabled on the device ("ip scp server enable").
let result = try await fileTransfer(
    sshConnection: connection,
    sourceFile: "test1.txt",
    destinationFile: "test1.txt",
    fileSystem: "flash:",
    direction: .put,
    overwriteFile: true,
    scpClient: NIOSCPClient(profile: connection.profile)
)

print(result.dictionary)
// ["file_exists": false, "file_transferred": true, "file_verified": true]

fileTransfer checks whether the destination exists, verifies free space, transfers, and MD5-verifies. For direct control, drive a FileTransfer yourself:

let transfer = try await FileTransfer(
    connection: connection,
    sourceFile: "test1.txt", destinationFile: "test1.txt",
    fileSystem: "flash:", direction: .put,
    scpClient: NIOSCPClient(profile: connection.profile)
)
try await transfer.establishSCPConnection()
try await transfer.transferFile()
let verified = try await transfer.verifyFile()
await transfer.closeSCPChannel()

Auto-detecting the device type

Over SSH

let probe = try await SSHDispatcher.connectHandler(profile: profile)

let guesser = try await SSHDetect(connection: probe)
// autodetect() disconnects `probe` itself before returning — don't call
// connection.disconnect() on it afterward.
let bestMatch = await guesser.autodetect()
print(bestMatch as Any)          // best-guess deviceType
print(guesser.potentialMatches)  // every rule that scored > 0, and its score

if let bestMatch {
    profile.deviceType = bestMatch
    let connection = try await SSHDispatcher.connectHandler(profile: profile)
}

Over SNMPv2c / SNMPv3

let detector = try SNMPDetect(
    hostname: "cisco1.lasthop.io",
    snmpVersion: .v2c,
    community: readSecurely("Enter SNMP community: ")
)
guard let deviceType = try await detector.autodetect() else {
    fatalError("SNMP failed!")
}

SNMPDetect needs an SNMPTransport implementation supplied to actually talk SNMP on the wire — Swiftmiko doesn't bundle one, matching Netmiko's own dependency on the external pysnmp package for this feature.

Terminal server and redispatch

Bouncing through a switch, into a terminal server over Telnet, then out a console port to a third device — using redispatch to swap the active driver at each hop without reconnecting: 

var connection = try await SSHDispatcher.connectHandler(
    profile: ConnectionProfile(
        host: publicIP, deviceType: "cisco_s300",
        username: "admin", auth: .password(readSecurely("Enter password of s300: "))
    )
)

// Telnet to the terminal server from the switch's own CLI.
try await connection.writeChannel("telnet \(terminalServerIP)\n")
try await connection.telnetLogin()

// Made it to the terminal server; redispatch to the real driver for
// whatever's actually attached to it.
connection = try await SSHDispatcher.redispatch(connection, deviceType: "cisco_ios")
try await connection.enterEnableMode(secret: readSecurely("Enter enable secret: "))

// Hop again to the end device via the terminal server (a Juniper SRX).
try await connection.writeChannel("srx2\n")
try await connection.telnetLogin()
connection = try await SSHDispatcher.redispatch(connection, deviceType: "juniper_junos")

let output = try await connection.sendCommand("show version")
await connection.disconnect()

Each call to redispatch returns a new connection object that now owns the channel — don't keep using the one you passed in. If the first hop has no real CLI to prepare a session against, connect with deviceType: "generic_termserver" (or its Telnet variant) instead of a real vendor driver, then redispatch once you've reached something with an actual CLI.

A note on structured output

Netmiko's use_textfsm/use_genie/use_ttp parsers have no Swift equivalent yet. sendCommand always returns a plain String; parsing that into structured data is currently left to the caller.
