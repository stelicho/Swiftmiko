Getting Started

Install the package and make your first connection.

Requirements

  • Xcode 16+ / Swift 5.9+
  • macOS 14+ (for the library target)

Installing

Swiftmiko is a Swift Package. Add it to your Package.swift:

dependencies: [
    .package(url: "https://github.com/stelicho/Swiftmiko.git", branch: "main")
]

Or in Xcode: File → Add Package Dependencies… and paste the repository URL.

Then add "Swiftmiko" as a dependency of your target and import Swiftmiko wherever you need it.

Your first connection

Every connection starts with a ConnectionProfile — a value type describing the host, credentials, and how to talk to it — and goes through SSHDispatcher.connectHandler(profile:), which looks up the right vendor driver for deviceType and opens the transport for you. 

import Swiftmiko

let profile = ConnectionProfile(
    host: "cisco1.lasthop.io",
    deviceType: "cisco_ios",
    username: "pyclass",
    auth: .password("your-password-here")
)

let connection = try await SSHDispatcher.connectHandler(profile: profile)
print(try await connection.findPrompt())
await connection.disconnect()

Breaking that down:

  • deviceType selects the driver — "cisco_ios", "juniper_junos", "arista_eos", and 150+ others. Passing an unregistered string throws SwiftmikoError.connectionFailed listing every currently supported type.
  • auth is an AuthMethod — .password(_:) here, or .keyFile(path:passphrase:) / .sshAgent for key-based auth.
  • connectHandler opens the transport (SSH, Telnet, or serial, chosen automatically from a _telnet/_serial suffix on deviceType) and runs the driver's session preparation (disabling paging, detecting the prompt) before returning.
  • disconnect() always closes the underlying transport cleanly — call it once you're done, including on error paths.
Never hardcode real credentials The snippets on this site use plain string literals for brevity. In real code, read passwords from a secure prompt, keychain, or environment variable — never commit them. Swiftmiko's own CLI tools use a small termios-based helper (promptSecure in Sources/CLITools/CommonOptions.swift) to read a password without echoing it to the terminal.

Running a command

sendCommand writes the command, waits for the device's prompt to reappear, and strips the echoed command and trailing prompt from the result: 

let output = try await connection.sendCommand("show ip int brief")
print(output)

Entering privileged (enable) mode

Devices that distinguish user vs. privileged EXEC mode need an explicit step before you can run config commands:

try await connection.enterEnableMode(secret: "enablepass")
